PWA Icon Generation Instructions

To generate proper PNG icons from the SVG:

  1. Use the icon-512x512.svg as base
  2. Generate PNG versions at: 72x72, 96x96, 128x128, 144x144, 152x152, 192x192, 384x384, 512x512
  3. Use a tool like RealFaviconGenerator

For now, the manifest.json references these sizes. Add PNGs when available.
