# Destination & Route Images

## Image Requirements
- Format: WebP preferred (JPEG fallback acceptable)
- Size: 400x300px recommended
- Aspect ratio: 4:3

## File Naming Convention

### Route Images (/images/routes/)
- delhi-mumbai.webp
- mumbai-bangalore.webp
- delhi-goa.webp
- bangalore-delhi.webp
- mumbai-goa.webp
- hyderabad-bangalore.webp

### Destination Images (/images/destinations/)
- mumbai.webp
- delhi.webp
- goa.webp
- bangalore.webp
- jaipur.webp
- chennai.webp

## Image Content Guidelines
- Routes: Show destination city skyline/landmark
- Destinations: City skyline, famous landmarks, or hotel exterior
- Keep images lightweight (<100KB each)
- Ensure proper licensing for commercial use
