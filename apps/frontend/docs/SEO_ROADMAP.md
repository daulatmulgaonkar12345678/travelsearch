# 6-Month SEO Roadmap for TravelSearch
## A Safe, Sustainable Strategy for a Newborn Travel Metasearch Platform

---

## Overview

This roadmap is designed for a **brand new domain** with:
- No existing authority
- Limited pages (home, flights, hotels, route pages)
- Focus on trust, speed, and clean UX

**Philosophy**: Slow, steady, quality-first growth. No shortcuts.

---

## Month 1: Foundation & Technical Hygiene

### Primary Goal
Ensure the site is crawlable, fast, and error-free.

### SEO Focus Areas

**Technical SEO (Priority)**
- [ ] Verify Google Search Console ownership
- [ ] Submit XML sitemap (`/sitemap.xml`)
- [ ] Check robots.txt allows crawling of important pages
- [ ] Ensure all pages return 200 status (no broken links)
- [ ] Verify canonical URLs are set correctly
- [ ] Check mobile responsiveness (100% of traffic will be mobile soon)

**On-Page SEO**
- [ ] Set unique `<title>` and `<meta description>` for:
  - Homepage
  - /flights (main)
  - /hotels (main)
  - Each existing route page (DEL→BOM, etc.)
- [ ] Add proper `<h1>` tags (only ONE per page)
- [ ] Ensure images have descriptive alt text

**Core Web Vitals**
- [ ] Test with PageSpeed Insights
- [ ] Target: LCP < 2.5s, CLS < 0.1
- [ ] Lazy-load below-fold images
- [ ] Optimize hero images (WebP, compressed)

### Pages to Work On
1. Homepage (highest priority)
2. /flights
3. /hotels
4. 6 existing route pages

### What NOT To Do
❌ Add more than 10 new pages  
❌ Buy backlinks  
❌ Add excessive keywords to titles  
❌ Create thin/duplicate content  

### Success Signals
✅ Site indexed in Google (check `site:yourdomain.com`)  
✅ 0 errors in Search Console  
✅ Core Web Vitals all green  
✅ All pages have unique meta titles

## Month 3: Local & Route Expansion (Careful)

### Primary Goal
Add 10-15 high-value route pages strategically.

### SEO Focus Areas

**Content Expansion (Controlled)**
- [ ] Identify top 10 searched routes (use Google Trends, not paid tools)
- [ ] Create 1-2 new route pages per week (MAX)
- [ ] Each page must have unique, useful content
- [ ] Add FAQs to route pages (natural language)

**On-Page Optimization**
- [ ] Optimize meta descriptions for CTR (include prices if stable)
- [ ] Add "Last updated" dates to route pages
- [ ] Ensure all new pages are in sitemap

**Image SEO**
- [ ] Add city/destination images to route pages
- [ ] All images: WebP format, compressed, proper alt text
- [ ] File names: `delhi-to-mumbai-flight.webp` (not `img123.webp`)

### Pages to Work On
- 10-15 new high-value route pages
- 3-5 new hotel destination pages

### What NOT To Do
❌ Create pages for routes with no search volume  
❌ Use same template text for all pages  
❌ Publish more than 2 pages per week  
❌ Add FlightOffer schema yet (wait until Month 5)  

### Success Signals
✅ New pages indexed within 1 week  
✅ Some impressions in Search Console  
✅ No manual actions or warnings  
✅ Bounce rate < 70%

**Content Polish**

❌ Add schema that doesn't match page content  
❌ Mark up fake FAQs

❌ Use schema for pages not indexed yet  

### Success Signals
✅ FAQ rich results appearing

## Technical SEO Reference Guide

### Metadata Structure

```
Title Format:
- Homepage: "TravelSearch - Compare Flight & Hotel Prices"
- Route: "Delhi to Mumbai Flights - Compare Prices | TravelSearch"
- Hotel: "Hotels in Goa - Compare Prices | TravelSearch"

Description Format:
- Homepage: "Compare flights and hotels from verified partners. 
  Transparent pricing, no hidden fees. Find your perfect journey."
- Route: "Compare Delhi to Mumbai flight prices. Direct flights 
  from ₹2,999. Search across airlines. No booking fees."
- Hotel: "Find hotels in Goa. Compare prices from trusted partners. 
  Beach resorts, budget stays, and luxury hotels."

Length:
- Title: 50-60 characters
- Description: 150-160 characters
```

### Canonical URL Strategy

```
Every page should have:
<link rel="canonical" href="https://yourdomain.com/page-url" />

Rules:
- Always use HTTPS
- Always use non-www (or www, pick one)
- No trailing slashes (or always trailing, be consistent)
- No query parameters in canonical
```

### Sitemap Strategy

```xml
<!-- Only include pages you want indexed -->
<url>
  <loc>https://yourdomain.com/flights/delhi-to-mumbai</loc>
  <lastmod>2025-01-15</lastmod>
  <changefreq>weekly</changefreq>
  <priority>0.8</priority>
</url>

Priority Guide:
- Homepage: 1.0
- Main category pages (/flights, /hotels): 0.9
- Popular routes: 0.8
- Other routes: 0.6
- Legal pages: 0.3
```

### Image SEO

```
File naming: delhi-to-mumbai-flight.webp (not IMG_1234.jpg)
Alt text: "Flights from Delhi to Mumbai" (descriptive, not stuffed)
Format: WebP preferred, JPEG fallback
Size: < 100KB for cards, < 200KB for heroes
Lazy loading: Yes for below-fold images
```

### Core Web Vitals Targets

```
LCP (Largest Contentful Paint): < 2.5 seconds
- Optimize hero images
- Use CDN for images
- Preload critical assets

CLS (Cumulative Layout Shift): < 0.1
- Set explicit dimensions on images
- Reserve space for dynamic content
- Avoid inserting content above existing content

INP (Interaction to Next Paint): < 200ms
- Minimize JavaScript
- Use code splitting
- Avoid long tasks
```

### Internal Linking Best Practices

```
DO:
- Link popular routes from homepage ✅
- Link related routes from route pages
- Use descriptive anchor text ("Delhi to Mumbai flights")
- Keep most important pages within 3 clicks of homepage

DON'T:
- Over-optimize anchor text (vary it naturally)
- Create orphan pages (no internal links)
- Use "click here" as anchor text
- Link to pages you don't want indexed
```

## Schema Implementation Timeline

| Month | Schema Type | Where | Notes |
|-------|-------------|-------|-------|
| 1 | None | - | Focus on basics |
| 2 | Organization | Homepage only | Basic trust signal |
| 3 | None new | - | Focus on content |
| 4 | None new | - | Focus on UX |

### Schema to AVOID Early

❌ **Review/Rating schema** - Need real reviews first  
❌ **Price schema** - Prices change, can cause issues  
❌ **Availability schema** - Requires real-time data  
❌ **Event schema** - Not applicable

## STOP Checklist (What NOT to Do in First 6 Months)

### Content
- ❌ Mass-generate pages with AI
- ❌ Copy content from competitors
- ❌ Create thin pages (< 300 words with no value)
- ❌ Publish more than 2-3 new pages per week
- ❌ Write content for bots, not humans

### Technical
- ❌ Block important pages in robots.txt
- ❌ Have multiple versions of same page (www/non-www)
- ❌ Ignore Core Web Vitals
- ❌ Use JavaScript-only rendering for critical content
- ❌ Have broken links (404s)

### Off-Page
- ❌ Buy backlinks
- ❌ Submit to low-quality directories
- ❌ Spam forums with links
- ❌ Exchange links aggressively
- ❌ Use PBNs (Private Blog Networks)

### Schema
- ❌ Add schema that doesn't match content
- ❌ Use Review schema without real reviews
- ❌ Mark up prices that change frequently
- ❌ Add schema to pages not indexed

### General
- ❌ Expect results in 1-2 months
- ❌ Change strategy based on daily fluctuations
- ❌ Ignore mobile experience
- ❌ Hide content behind pop-ups
- ❌ Use aggressive interstitials

## SEO Philosophy for Newborn Websites

### The Mindset

> "SEO for a new website is like growing a tree. 
> You can't make it grow faster by pulling on it. 
> You can only ensure it has good soil, water, and sunlight."

### Core Principles

1. **Patience is Non-Negotiable**
   - Expect minimal results for 3-6 months
   - Domain authority takes years, not weeks
   - Early traffic will come from long-tail, low-competition queries

2. **Quality Over Quantity**
   - 10 excellent pages > 100 mediocre pages
   - One genuine backlink > 100 spammy links
   - Real engagement > fake metrics

3. **User-First, Always**
   - Would a real user find this page helpful?
   - Does this content answer their question?
   - Is the experience fast and pleasant?

4. **Technical Foundation Matters**
   - Speed is a ranking factor
   - Mobile-first is mandatory
   - Clean code = easier crawling

5. **Consistency Beats Intensity**
   - 2 pages/week for 6 months > 50 pages in week 1
   - Regular improvements > occasional overhauls
   - Steady progress > explosive launches

### What Success Looks Like

**Month 1-3**: "Nothing is happening" (normal)
- Site is indexed
- No errors
- No penalties

**Month 4-6**: "Small signs of life"
- Some impressions
- A few clicks
- Rankings for branded terms

**Month 7-12**: "Building momentum"
- Growing impressions
- More clicks
- Rankings for some non-branded terms

**Year 2+**: "Sustainable growth"
- Consistent traffic growth
- Rankings improving
- Content earning links naturally

### Final Advice

> "The best SEO strategy for a new website is to build something 
> genuinely useful, make it technically excellent, and be patient. 
> There are no shortcuts worth taking."
