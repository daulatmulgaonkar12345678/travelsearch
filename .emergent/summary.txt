**Code Architecture**


**Key Technical Concepts**
-   **State Network Rule:** An architectural principle ensuring that any bus search within Maharashtra always yields a result (either a direct MSRTC offer or a generic redirect card), preventing false negatives.
-   **Strict ID-Based Search:** The frontend was refactored to use a unique  from the autocomplete selection as the source of truth for searches. This decouples user intent from ambiguous text input and fixed the destination overwrite bug.
-   **Layered Route Resolution:** The backend uses a chain of resolvers (MSRTC exact match -> State Network fallback -> Feeder link) to find connectivity, while a separate corridor resolver enhances results with Likely Stops.
-   **Slug-Only Deep Linking:** The new, mandatory strategy for generating links to booking partners. It relies on a centralized utility () to create clean, normalized, human-readable URL paths (e.g., ) instead of fragile query parameters.
