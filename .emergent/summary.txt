**Key Technical Concepts**
-   **API Proxy Architecture (Next.js):** The core concept of this session. Using Next.js API routes as a mandatory middle layer to proxy all frontend requests to the backend. This solves CORS issues and isolates environment-specific URLs to the server side.
-   **Transparent Proxy:** A proxy that forwards requests and responses without modification (no filtering, fallbacks, or data transformation). This was a strict requirement.
-   **Vendor-Specific Deep Linking:** Generating affiliate URLs based on precise, documented patterns for different vendors (MakeMyTrip, Agoda, redBus, etc.) instead of relying on a single aggregator's gateway. This logic is now centralized in a frontend library.
