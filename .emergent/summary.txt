**Key Technical Concepts**
- **Hybrid Supplier Protection:** A system that avoids a Redis dependency by combining local in-memory token buckets (for immediate RPS limiting) with a shared database (MongoDB) for global state (per-minute quotas and circuit breaker status).
- **Configuration Caching:** The core of the current problem. The Python application (likely via  or module imports) is caching old environment variables and is not reloading them despite restarts.
- **Fail-Open Principle:** The protection system is designed to fail open, meaning if the database is unavailable, it will fall back to more restrictive local-only rate limiting but still allow requests, prioritizing availability.
